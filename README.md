# AERA — Autonomy, Engineered

Cinematic marketing landing page for **Aera Motor Co.**

Stack: Vite + React + TypeScript + Tailwind CSS + GSAP.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Provenance

Exported from [`fleekelon/fleekelon`](https://github.com/fleekelon/fleekelon) branch `cursor/aera-cinematic-landing-a525` (`aera-site/`). Kept as a dedicated marketing demo, separate from the personal toolkit/profile repo.
